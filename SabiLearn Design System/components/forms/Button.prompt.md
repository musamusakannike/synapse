Primary action button — pill-shaped, warm-green fill, used for the single dominant action on a screen.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Start lesson</Button>
```

Variants: `primary` (default CTA), `secondary` (tinted, secondary actions), `ghost` (bordered, tertiary), `accent` (gold, celebratory/reward CTAs like "Claim XP"). Sizes: `sm`, `md`, `lg`. Always pill radius — never square.
